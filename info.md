# IP2Location.io

Display geolocation information for an IP address in Home Assistant using the
[IP2Location.io](https://www.ip2location.io/) web service.

- Country, region, city, ZIP code, latitude, longitude and time zone.
- Network data: ASN, AS name, ISP and connection type (plan dependent).
- A diagnostic binary sensor for proxy / VPN / Tor detection.
- A device tracker so the location appears on the Home Assistant map.
- Works without an API key, or with a free key for a much higher quota.

See the [README](README.md) for installation and configuration instructions.
